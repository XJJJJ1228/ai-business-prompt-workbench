# 任务
阅读下方【原始文本】，从中提取信息，严格按照下面固定JSON格式输出。
提取范围：核心结论、关键数据、待办事项、风险/问题。
规则：
1. 所有提取内容**必须来自原文，严禁虚构、脑补原文没有的人名、时间、数字**；不确定的内容标注【原文未明确】。
2. 待办事项必须拆分：事项内容、负责人、截止时间；原文没有就填“未提及”。
3. 不要额外润色扩写，不要添加原文不存在的观点。
4. 不要输出JSON以外多余的解释文字，只返回JSON。
