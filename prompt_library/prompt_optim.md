# 迭代总体思路（通用 AI 优化公式）

1. 加角色：让模型进入专业职场身份，避免口语化、随意输出
2. 加约束：明确禁止编造、禁止脑补、禁止夸大、禁止冗余
3. 加结构：强制固定输出格式，解决每次结果不一样的问题
4. 加溯源：要求所有内容必须基于原文，解决幻觉
5. 加自检：让 AI 自我纠错，降低人工复核成本

# 分项迭代记录

1. 长文本信息抽取 Prompt 迭代

 初始问题（V1）
- 输出自由散漫，无结构化
- 经常遗漏待办事项、风险点
- 无法用于企业归档

 优化策略（升级至 V2）
- 增加「企业文档分析师」角色
- 强制拆分：结论 / 数据 / 待办 / 风险四大模块
- 强制 JSON 结构化输出
- 增加「禁止编造、未明确标注」规则

 迭代效果
输出标准化、可直接入库，适合会议纪要、业务归档。

---

2. 业务文案生成 Prompt 迭代

 初始问题（V1）
- 虚构产品功能、虚构数据
- 文风不稳定，时而夸张时而随意
- 存在广告法违规风险

 优化策略（升级至 V2）
- 增设品牌文案专员角色
- 强制所有卖点必须素材溯源
- 增加合规禁止夸大约束
- 增加「AI 自检依据」模块

 迭代效果
杜绝虚假宣传，文案合规、风格统一，可直接作为职场初稿使用。

---

3. 知识库 FAQ Prompt 迭代

 初始问题（V1）
- 问题杂乱、重复、不成体系
- 强行生成原文没有的功能

 优化策略（升级至 V2）
- 强制三分结构：认知类 / 操作类 / 问题类
- 禁止无中生有
- 合并相似问答，标准化知识库风格

 迭代效果
零散资料快速变成企业标准化帮助中心知识库。

---

4. AI 内容审核 Prompt 迭代

 初始问题（V1）
- 仅检查错别字，无业务审核能力
- 无法识别幻觉、逻辑错误、合规风险

 优化策略（升级至 V2）
- 建立五维审核体系：事实、逻辑、完整、合规、文风
- 强制标注错误位置 + 原因 + 修改方案
- 输出修正终稿

 迭代效果
实现「AI 生成 + AI 自检」双保险工作流，大幅降低人工成本。

# 全局通用优化总结

通过本轮项目迭代，总结出业务层 Prompt 工程通用优化逻辑：

1. 无约束 = 不稳定：简单自由指令一定会出现幻觉和乱输出
2. 无结构 = 不可用：职场 AI 输出必须结构化，才能落地归档
3. 无溯源 = 不安全：不做素材绑定，一定会编造信息
4. 无自检 = 不闭环：AI 生成后必须二次风控，才能满足企业合规标准

# 项目收获

摆脱 “单纯提问 AI” 的浅层使用方式
具备诊断 AI 缺陷、定制业务指令、量化输出质量、搭建 AI 工作流的职场 AI 应用能力
适配 AI 内容运营、提示词工程、产品助理、数字化实施岗位
