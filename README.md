# AI 业务提示词与内容质量管控工作台

## 项目简介

本项目是**面向职场通用业务的 AI 文本数字化落地开源项目**，主打**大模型提示词工程、AI 内容质量治理、企业文本自动化工作流**。

区别于纯技术开发项目，本项目从**业务落地视角**出发，聚焦企业高频痛点：大模型输出不稳定、幻觉严重、格式混乱、内容不符合职场规范、人工复核成本高。

结合文本理解、逻辑梳理、语言风控能力，搭建一套**可直接复用、可迭代、可量化**的 AI 文本处理体系，适用于：文案生产、会议纪要、资料萃取、知识库搭建、内容合规自检等职场场景。

项目**零深度代码开发**，全部基于业务层 AI 应用与流程标准化，非常适配 AI 提示词运营、AI 内容治理、AI 产品助理、数字化实施、智能文案岗位求职。

## 项目核心亮点

1. **系统化提示词工程**
针对职场多场景完成分层 Prompt 设计，包含角色约束、格式约束、事实约束、防幻觉约束，持续迭代版本，解决大模型输出随机性问题。
2. **AI 内容量化评估体系**
自建**5 维业务评分标准**（准确性、完整性、逻辑性、合规性、文风匹配度），把 “AI 好不好用” 从主观感受变成**可量化打分**，实现 AI 内容标准化质检。
3. **端到端 AI 业务工作流**
搭建企业可用的文本自动化流水线：原始素材 → 智能萃取 → 内容生成 → AI 自检风控 → 人工复核 → 定稿输出，模拟真实企业数字化作业流程。
4. **AI 幻觉治理与问题复盘**
沉淀多组真实模型出错案例（编造信息、遗漏关键信息、文风跑偏、逻辑错乱），记录优化方案与迭代过程，形成可复用的 AI 风控经验。

## 核心功能介绍

### 1. 多场景分层提示词体系（核心能力）

摒弃网络通用简陋 Prompt，采用**结构化分层提示词设计**：

- 任务目标层：明确模型输出目的
- 角色身份层：限定输出专业口吻
- 格式约束层：统一职场规范格式
- 事实风控层：禁止编造、要求溯源
- 优化迭代层：根据输出问题持续调优

覆盖企业最高频 3 大 AI 应用场景：

- 长文本提炼：会议纪要、调研报告、学习资料萃取
- 内容创作：品牌文案、宣传文稿、职场推文
- 知识沉淀：产品 FAQ、知识库整理、问题结构化

### 2. 自建 AI 内容质量评估模型

针对职场内容落地痛点，制定**五大量化考核维度**：

- 事实准确性：无编造、无时间 / 人物 / 数据错误
- 信息完整性：不遗漏关键业务信息
- 逻辑严谨性：层级清晰、因果通顺
- 内容合规性：无违规表述、符合职场规范
- 文风适配性：匹配官方 / 活泼 / 严谨等指定风格

实现**AI 输出可测评、可对比、可优化**，解决企业 AI 落地无标准、无考核的行业痛点。

### 3. 标准化 AI 自动化工作流

搭建企业轻量化智能文本处理流水线：

1. 原始长文本素材输入
2. AI 结构化信息抽取
3. 业务内容生成 / 改写
4. AI 自我校验纠错
5. 人工二次精修定稿
6. 归档沉淀为标准化知识资产

大幅降低重复文案、资料整理、纪要梳理的人工成本。

## 🎬 项目演示 Demo
> 业务场景：企业客服知识库FAQ自动化构建
### 输入素材
一堆未结构化的客服聊天原始文本（脱敏模拟数据，存放于`data/`文件夹），包含客户重复提问、模糊表述、零散回答。
### 执行流程
1. 调用仓库【知识库FAQ构建提示词】，输入原始对话文本；强制要求模型区分：标准问题、标准答案、边界例外场景。
2. 调用【AI内容风控审核Prompt】对生成FAQ做合规校验。
3. 使用自研**五维量化评估表**打分，检查幻觉、事实错误、表述歧义。
4. 输出标准化FAQ文档，可直接导入企业内部知识库。

### 效果对比
✅ 普通直接提问AI：
输出问答格式混乱，部分回答编造不存在的政策，问题重复冗余，无法直接投入业务使用。

✅ 使用本项目优化Prompt + 评估校验流程：
输出固定Markdown表格格式，所有回答必须标注信息来源；识别出AI编造内容并拦截；合并相似问题，产出可直接交付业务的FAQ文档。

> 更多实战案例：`docs/`目录下包含会议纪要萃取、产品合规文案生成、知识库构建3份完整评估报告。
