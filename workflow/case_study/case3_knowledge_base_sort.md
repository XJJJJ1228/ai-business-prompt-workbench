## 案例概述

本案例模拟企业**零散产品资料 → 标准化用户 FAQ 知识库**完整落地场景。
企业普遍存在产品资料散乱、话术不统一、用户咨询重复度高、无统一帮助文档的问题。
本案例使用自研 FAQ 生成提示词，实现**无序素材自动分类、自动问答、去重规整**，快速搭建可用的产品知识库。

## 一、业务场景

- 场景：产品帮助中心、用户知识库、客服问答库搭建
- 痛点：原始资料碎片化、无结构、无问答体系
- 目标：自动整理为「认知类 / 操作类 / 故障类」标准 FAQ，可直接用于对内培训、对外用户答疑

## 二、原始零散业务素材

```
AI业务文档助手仅支持纯文本处理，不支持PDF、图片、表格识别。
基础版用户单次最多处理5000字文本内容，完全免费使用。
高级版会员99元/月，单次支持2万字长文本处理。
工具主要用于长文本摘要、信息抽取、会议纪要结构化整理。
所有功能网页端在线使用，无需下载软件、无需安装、无需代码。
超长文本建议分段处理，避免内容截断缺失。
暂无批量导入功能，仅支持单次文本输入处理。
```

## 三、使用工具

- 优化 Prompt：faq_generation.md V2 结构化知识库提示词
- 评估标准：项目五维量化评估体系

## 四、优化前（V1 简单 Prompt 输出问题）

### V1 简单指令

```
根据以上资料生成FAQ。
```

### V1 劣质输出问题

1. 问答杂乱无序、重复提问
2. 容易脑补额外功能、编造权限
3. 没有分类，无法直接做成知识库
4. 关键使用限制、收费规则遗漏严重

## 五、优化后（V2 标准化完整输出）

### 一、基础认知类

1. Q：AI 业务文档助手的核心功能是什么？
A：支持长文本智能摘要、结构化信息抽取、会议纪要整理，主打办公文本智能化处理。
2. Q：工具的使用门槛高吗？
A：门槛极低，网页端直接在线使用，无需下载、无需安装、无需代码基础。

### 二、使用操作类

1. Q：免费版和高级版有什么区别？
A：基础版永久免费，单次最高处理 5000 字文本；高级版 99 元 / 月，单次最高支持 2 万字长文本处理。
2. Q：超长文本如何处理效果最好？
A：超长内容建议分段输入处理，避免模型上下文截断导致内容缺失。

### 三、问题限制类

1. Q：工具支持 PDF、图片、表格识别吗？
A：不支持，目前仅支持纯文本内容处理。
2. Q：是否支持批量文本导入处理？
A：暂未上线批量导入功能，仅支持单次手动输入文本处理。

## 六、案例复盘与业务价值

1. **无序资料结构化**：把碎片化、零散式的产品说明，自动梳理成体系化知识库
2. **统一对外话术**：解决团队答疑口径不统一、解释不一致的业务问题
3. **零幻觉产出**：严格溯源原始素材，无编造、无夸大、无新增功能
4. **可直接落地**：输出结构符合企业帮助中心、客服问答库标准，可直接复用

## 七、案例总结

普通 AI 生成 FAQ 混乱、不可复用。
通过**分类约束 + 去重规则 + 素材溯源 + 标准化格式**的 Prompt 工程优化，
可以快速完成企业知识库数字化沉淀，是 AI 内容运营、产品助理、数字化岗位的核心实操能力。
