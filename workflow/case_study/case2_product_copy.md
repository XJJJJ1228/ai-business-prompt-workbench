## 案例概述

本案例模拟企业**产品对外宣传文案自动化生成**场景。
针对普通 AI 容易虚构卖点、夸大宣传、违反广告法、风格不稳定的问题，使用自研分层文案 Prompt，实现**素材溯源、合规自检、风格统一**的智能文案产出。

## 一、业务场景

- 场景：企业新产品官网简介、轻量化宣传文案撰写
- 职场痛点：人工写文案耗时久、风格不统一、容易出现违规宣传话术、AI 容易编造虚假卖点
- 优化目标：基于真实产品素材，产出**100% 属实、合规、风格统一**的职场可用文案初稿

## 二、原始产品素材

```
产品名称：AI业务文档助手
核心功能：长文本摘要、结构化信息抽取
使用方式：网页端在线使用，无需下载、无需代码基础
版本定价：基础版免费（单次5000字），高级版99元/月（单次2万字）
使用限制：仅支持纯文本处理，不支持PDF、图片、表格识别
适用人群：行政、产品、运营中小团队
```

## 三、使用工具

- 优化 Prompt：copywriting.md V2 合规文案生成提示词
- 评估标准：项目五维量化评估体系

## 四、优化前（V1 简陋 Prompt 输出问题）

### V1 简单指令

```
帮我写一段专业的产品宣传文案。
```

### V1 劣质 AI 输出

> 
> AI 文档助手是一款全能智能办公神器，支持 PDF、图片、表格识别，功能强大、全网领先，能够全方位解决企业办公痛点，是各行各业的最优选择。

### 存在严重问题

1. **严重 AI 幻觉**：编造 PDF / 图片识别功能（素材无对应信息）
2. **广告法违规**：“全能、全网领先、最优选择” 绝对化违禁词
3. **信息失真**：无价格、无使用门槛、无真实功能介绍
4. **完全不可用**：存在合规风险，企业无法对外发布

## 五、优化后（V2 项目级 Prompt 标准输出）

> 
> # AI 业务文档助手｜中小团队轻量化智能办公工具
> 
> 
> AI 业务文档助手是面向行政、产品、运营团队的轻量化文本处理工具，无需下载客户端、无需代码基础，网页端即可直接使用。
> 
> 
> 工具核心聚焦长文本办公提效，支持**长文本智能摘要、结构化信息抽取**两大核心功能，能够快速梳理会议文稿、业务资料、调研报告等海量文本内容，大幅降低人工整理成本。
> 
> 
> 产品采用分层收费模式，适配不同团队需求：基础版免费开放，单次可处理 5000 字文本；高阶需求可开通高级版，99 元 / 月，单次支持 2 万字长文本处理。
> 
> 
> 目前产品仅支持纯文本内容处理，暂不支持 PDF、图片、表格类文件识别，适配中小团队日常文本数字化办公场景。

### 自检溯源说明（核心加分项）

1. 功能描述：长文本摘要、信息抽取（素材原文）
2. 使用方式：网页在线、无代码、无需下载（素材原文）
3. 价格体系：免费版 / 99 元高级版、字数限制（素材原文）
4. 使用限制：仅支持纯文本（素材原文）
5. 规避所有绝对化宣传用语，完全合规

## 六、案例复盘与业务价值

1. **彻底解决 AI 幻觉问题**：通过素材强制溯源约束，杜绝虚构功能、虚假卖点
2. **解决合规风险**：规避广告法违禁词，适配企业对外宣传标准
3. **标准化产出**：文风专业统一，无需大幅修改即可作为文案初稿
4. **降本提效**：将 30 分钟文案撰写工作，压缩至 1 分钟 AI 生成 + 微调

## 七、案例总结

普通 AI 文案生成**自由且不可控**，企业无法落地。
通过**角色约束 + 合规约束 + 素材溯源 + 自检机制**的 Prompt 工程优化，可将 AI 从 “娱乐工具” 转化为**企业可用的数字化生产工具**。
